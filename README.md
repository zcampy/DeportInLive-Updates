# DeportInLive Updates

Canal público de actualizaciones de DeportInLive.

Para publicar una actualización:

1. Incrementa `versionCode` y `versionName` en la aplicación.
2. Genera la nueva APK utilizando siempre la misma firma.
3. Sustituye `DeportInLive.apk` en este repositorio.
4. Actualiza `version` y `notes` en `update.json` para que coincidan con la APK.
5. Publica la APK antes que el manifiesto si realizas commits separados.

No añadas a este repositorio el código fuente ni claves de firma.
